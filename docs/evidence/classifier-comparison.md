# Handoff and intent classifier: rules vs trained model vs LLM

Trained on `classifier.v1`: evals/datasets/train.synthetic.jsonl (synthetic, template-generated, disjoint from the evaluation sets).
Handoff threshold 0.95 chosen on the dev split (no added false handoffs over rules alone).
Generated by `python -m frontdesk_ml.classifier compare`. Latency is per message on the CI runner class of machine.
Decision: the rules act; the model runs in shadow mode (its prediction is stored in each event payload, `shadow`). Revisit when a model retrained on a client's consented data beats the rules on that client's holdout.
